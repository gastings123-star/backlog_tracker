# Трекер согласования бэклога

Однофайловое веб-приложение для согласования бэклога между бизнесом и командами разработки. Работает полностью в браузере, без бэкенда. Данные хранятся в `localStorage` пользователя.

## Возможности

- Команды с лимитами по аналитике / разработке / тестированию.
- Задачи: оценка А/Р/Т в днях, приоритет, ценность, эффект, смежные системы, стейкхолдер, Jira, SD, комментарий.
- Статусы: «На рассмотрении» → «Утверждено» / «Отклонено», с возможностью вернуть.
- Фильтры и сортировки (по приоритету, статусу, рангу).
- Импорт задач из Excel/CSV с автосопоставлением колонок.
- Экспорт и импорт JSON-бэкапа (полное состояние).

## Запуск локально

Достаточно открыть `index.html` в браузере. Если используется встроенный лёгкий веб-сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация в интернете

Подходит любой статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages, S3 + CloudFront). Достаточно опубликовать содержимое корня репозитория.

Пример для GitHub Pages: Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.

## Импорт задач из Excel

1. Скачайте `templates/tasks-import-template.xlsx`.
2. Заполните лист «Задачи» (обязательное поле — «Название»).
3. В трекере: «Импорт» → выберите файл. Колонки сопоставятся автоматически.

Распознаваемые значения приоритета: `Высокий / Средний / Низкий` либо `High / Medium / Low`. Импортированные задачи попадают в статус «На рассмотрении» без привязки к команде.

## Пересборка шаблона

```bash
pip install --user openpyxl
python3 scripts/build_template.py
```

## Хранение данных

Данные пользователя сохраняются в `localStorage` ключ `backlog_tracker_v2`. У каждого пользователя своя локальная база — общего бэклога между устройствами/браузерами нет. Для обмена используйте JSON-бэкап (кнопки «Экспорт» / «Импорт JSON»).
